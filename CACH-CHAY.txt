========================================================
 CHEF MINH NGUYEN — WEBSITE
========================================================

A. XEM THU TREN MAY (XAMPP)

 1. Giai nen file zip ra o dia
    (chuot phai > Extract All)
    KHONG bam dup index.html ngay trong cua so ZIP.
    Lam vay Windows chi lay mot file, css/ js/ assets/
    khong di theo, trang se hien ra tro trui.

 2. Chep ca thu muc "chefminh" vao:
       C:\xampp\htdocs\

 3. XAMPP Control Panel > Start o dong Apache

 4. Mo trinh duyet:
       http://localhost/chefminh/

 Form dang ky se ghi vao file lien-he.csv
 (nam cung thu muc, mo bang Excel)


B. DUA LEN GITHUB PAGES

 1. Tao repository moi, de Public.

 2. Upload TAT CA file va thu muc, giu nguyen cau truc.
    Nho lay ca file .nojekyll va CNAME
    (Windows an file bat dau bang dau cham -
     bat "Hidden items" trong View de thay).

 3. Settings > Pages
      Source: Deploy from a branch
      Branch: main   Folder: / (root)

 4. Doi 1-2 phut. Link tam:
       https://<tai-khoan>.github.io/<ten-repo>/

 5. Gan ten mien that:
    File CNAME da ghi san chefminhnguyen.com
    Vao nha cung cap ten mien, them:

      A     @     185.199.108.153
      A     @     185.199.109.153
      A     @     185.199.110.153
      A     @     185.199.111.153
      CNAME www   <tai-khoan>.github.io

 6. Quay lai Settings > Pages, tick Enforce HTTPS
    (co the phai doi den 24h de DNS lan truyen)


C. TRUOC KHI CONG BO — VIEC PHAI LAM

 1. Form dang ky hien CHUA gui di dau ca.
    Mo js/main.js, dong thu 2 tu tren:
       var FORM_ACCESS_KEY = '';
    Lay key mien phi tai web3forms.com (nhap
    thaiminhchef@gmail.com), dan vao giua hai dau nhay.
    Xong thi moi thong tin khach dien se gui thang
    ve hop thu Chef.

 2. Trang press.html: cac nut "Doc bai viet" dang khoa
    vi chua co link bai bao that.

 3. Ba bai blog dang co banner do "CAN CHEF DUYET".
    Chef doc, sua, roi xoa dong do trong tung file
    o thu muc blog/

 4. Xem muc 4 trong README.md - danh sach viec
    can Chef xac nhan (ten tren giay chung nhan,
    ban quyen anh, anh gan sai mon...)


D. LOI THUONG GAP

 Trang tro trui, khong mau
   -> Chua giai nen day du. Xem muc A.1

 Apache khong start
   -> Cong 80 bi chiem (Skype/IIS).
      XAMPP > Config > httpd.conf > doi Listen 80
      thanh Listen 8080 > vao localhost:8080/chefminh/

 Video khong co tieng
   -> Dung. Trinh duyet chan video tu phat co tieng.
      Bam nut o goc duoi ben phai de bat.

 Anh khong hien tren GitHub
   -> Thieu thu muc assets/ khi upload,
      hoac thieu file .nojekyll
